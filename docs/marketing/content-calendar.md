# Ninety-day content calendar

## Weekly cadence

| Day | Franchise | Required asset | Conversion goal |
|---|---|---|---|
| Monday | Pick Your Goon | Same-discipline matchup card | Roster views |
| Tuesday | Call the Trick | 6–12 second clip or freeze frame | Replies and predictions |
| Wednesday | Inside the Gooniverse | Character art, traits, lore, ZERO-G world | Character views |
| Thursday | Product Proof | One complete workflow capture | Wallet connections |
| Friday | Goon League Night | Match card, countdown, Arena link | Live viewers and matches |
| Saturday | Discipline Community | Sport-native educational or cultural post | Qualified discovery |
| Sunday | Build Report | Transparent metric card | Trust and retention |

## Publishing gate

Every post must answer yes to at least one:

- Does it show the product working?
- Does it teach a game or sport mechanic?
- Does it establish a character or rivalry?
- Does it report a real milestone or result?
- Does it make a relevant contribution to somebody else's conversation?

If every answer is no, do not publish it.
